  <action>
Create `03_software/` directory and write `01_fpga_pipeline.md` following the document template from conventions.md. The document MUST follow signal-flow organization (not module-by-module), tracing data from ADC input to USB output.

**Document structure:**

1. **Header** -- Purpose, prerequisites (symbol table, parameter table, conventions), and document scope
2. **Pipeline Overview** -- High-level signal flow diagram as a table showing all 10 stages from research Pattern 1, with clock domain for each stage
3. **Clock Domain Map** -- Table showing each module and its operating clock domain (400 MHz ADC, 100 MHz system, FT601 100 MHz). Reference `02_hardware/05_fpga_board.md` for clock tree details.
4. **Stage 1: ADC Acquisition** -- `ad9484_interface_400m.v` + `lvds_to_cmos_400m.v`. 8-bit LVDS at 400 MHz to CMOS conversion. CDC crossing to processing domain.
5. **Stage 2: Digital Down-Conversion** -- `ddc_400m_enhanced`. NCO phase increment derivation as tagged equation:

$$
\Delta\phi_\text{NCO} = \frac{f_\text{IF}}{f_s} \times 2^{32} \tag{SW-1}
$$

Show numerical verification: $\frac{120 \times 10^6}{400 \times 10^6} \times 2^{32} = 0\text{x4CCCCCCD}$. Document LFSR phase dithering for spur reduction. Mixer output bit width: 34-bit (18-bit x 16-bit).

6. **Stage 3: CIC Decimation** -- `cic_decimator_4x_enhanced`. Document CIC gain equation:

$$
G_\text{CIC} = D_\text{CIC}^{N_\text{CIC}} = 4^5 = 1024 = 2^{10} \tag{SW-2}
$$

This derives the `>>> 10` right shift. Input: 18-bit at 400 MHz, output: 18-bit at 100 MHz. Saturation detection with latched overflow monitoring.

7. **Stage 4: FIR Compensation** -- `fir_lowpass_parallel_enhanced`. CIC passband droop compensation. CDC crossing from 400 MHz to 100 MHz. Dual I/Q channels.

8. **Stage 5: DDC Output Interface** -- `ddc_input_interface`. Scaling and alignment. Data sync error detection.

9. **Stage 6: Matched Filter** -- `matched_filter_multi_segment`. Overlap-save method. Document the 8-state FSM (IDLE -> COLLECT_DATA -> ZERO_PAD -> WAIT_REF -> PROCESSING -> WAIT_FFT -> OUTPUT -> NEXT_SEGMENT). Long chirp: 3000 samples -> 4 segments ($L_\text{adv}=896$, $L_\text{overlap}=128$). Short chirp: 1 segment zero-padded to 1024. Reference chirp loading via `chirp_memory_loader_param`. Latency buffer (3187 cycles) for reference alignment. Cross-reference matched filter theory in Phase 2 physics (Eq. LFM-series).

10. **Stage 7: Range Bin Decimation** -- `range_bin_decimator`. 1024 bins -> 64 bins ($D_\text{rb} = 16$, peak detection mode). Purpose: reduce data volume before Doppler processing.

11. **Stage 8: Doppler Processing** -- `doppler_processor_optimized`. 32-pt FFT across 32 chirps for each of 64 range bins. Hamming window in Q15 format. Memory layout: chirp-major addressing `addr = chirp_index * N_\text{rb} + range_bin`. Uses Xilinx `xfft_32` IP core. Output: 32-bit packed `{Q[15:0], I[15:0]}`.

12. **Stage 9: Threshold Detection** -- In `radar_system_top.v`. **CRITICAL:** Document honestly as placeholder threshold detection, NOT true CFAR: `|I| + |Q| > 10000`. Note that variable names (`rx_cfar_detection`, `cfar_valid`) use CFAR terminology but the implementation is a fixed magnitude threshold. Reference Phase 5 SWRES-01 for future CFAR implementation research.

13. **Stage 10: USB Output** -- Brief forward-reference to `04_usb_protocol.md` (SWDOC-04) for full protocol details. Note FT601 Slave FIFO mode, `ft601_clk_in` (100 MHz, asynchronous to system clocks).

14. **STM32-to-FPGA Control Interface** -- Table of control signals (stm32_new_chirp PD8, stm32_new_elevation PD9, stm32_new_azimuth PD10, stm32_mixers_enable PD11, FPGA reset PD12). How chirp/elevation/azimuth edges trigger pipeline state transitions.

15. **References** -- Symbol table, parameter table, Phase 2 physics, Phase 3 hardware docs.
