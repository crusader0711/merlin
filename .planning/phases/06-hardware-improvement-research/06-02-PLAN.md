**Section 5: Antenna Array Expansion (HWRES-05):**

5.1 Current State:
- 16-element uniform linear array (ULA), d = lambda/2 = 14.3 mm at 10.5 GHz
- ADAR1000: 4 devices, 2-bit DEV_ADDR (addresses 0x00-0x03), 4 channels each
- SPI bus: SPI1 on STM32, single bus with 4 chip selects
- Beamwidth: ~6.3 degrees at broadside
- Scan range: +/-62.7 degrees mechanical, +/-33 degrees practical for acceptable sidelobes
- Cross-reference `02_hardware/04_antenna_beamforming.md` Section 2.2 for current SPI mapping

5.2 Literature Survey:
- Scaling analysis table from 06-RESEARCH.md (16/32/64 elements with ADAR1000 count, SPI buses, array gain, beamwidth, aperture, range multiplier)
- Array gain calculation using existing physics: $10\log_{10}(N)$ from `01_physics/03_beamforming_theory.md`
- Range improvement: $R_{max} \propto G^{1/2}$, so 32 elements = 1.41x range, 64 elements = 2.0x range
- Reference grating lobe analysis Eq. BF-10: with d = lambda/2 maintained, grating lobes remain outside visible space

5.3 Gap Analysis:
- CRITICAL SPI scaling constraint (Pitfall 4 from research):
  - ADAR1000 DEV_ADDR is 2 bits: max 4 devices per SPI bus
  - 32 elements = 8 ADAR1000 = 2 SPI buses required
  - 64 elements = 16 ADAR1000 = 4 SPI buses required
  - STM32F746 has SPI1-SPI6 (6 total), SPI1 (ADAR1000) and SPI4 (AD9523/ADF4382) currently used, SPI2/3/5/6 available
- Physical constraint: 64-element array at lambda/2 spans 900 mm (~35 inches) -- may exceed platform mechanical constraints
- Beam steering time: SPI programming time per beam position increases linearly with ADAR1000 count (31 elevation positions x M=32 chirps each)
- Quantify gain and beamwidth improvements using existing beamforming equations (not re-deriving)

5.4 Feasibility Assessment:
- 32-element expansion: MODERATE complexity -- 1 additional SPI bus, ~2x PCB length, firmware changes for dual-bus SPI control
- 64-element expansion: HIGH complexity -- 3 additional SPI buses, ~4x PCB length, potential mechanical platform redesign
- For both: power budget scales linearly (16 more ADTR1107 T/R modules for 32-element, 48 more for 64-element)
- Variant impact: Nexus platform may not support 64-element physically; Extended platform has more space

5.5 Recommendations:
- 32-element expansion is the practical near-term upgrade path (moderate complexity, meaningful 3 dB gain, 1.41x range)
- 64-element expansion is viable but requires platform redesign assessment
- Recommended investigation: prototype 32-element array on Extended platform, measure actual beam pattern vs theoretical
- Priority: MEDIUM-HIGH -- array expansion provides guaranteed improvement with well-understood physics
