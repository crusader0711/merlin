**Section 4: Higher-Resolution ADC Options (HWRES-04):**

4.1 Current State:
- AD9484: 8-bit (NOT 14-bit -- cite Pitfall 1 from research, reference `02_hardware/02_rf_frontend.md` Section 4 and `ddc_400m.v` ADC_WIDTH = 8)
- Sample rate: 400 MSPS (operated), 500 MSPS rated
- ENOB: ~7.5 bits typical
- SQNR: 49.9 dB theoretical (from Eq. NF-11: $\text{SQNR} = 6.02b + 1.76~\text{dB}$)
- Interface: 8-bit parallel LVDS DDR
- FPGA interface: `ad9484_interface_400m.v` with IBUFDS + IDDR primitives

4.2 Literature Survey:
- Candidate comparison table from 06-RESEARCH.md: AD9484 (current) vs AD9680 (14-bit, 500 MSPS) vs AD9208 (14-bit, 3 GSPS)
- Include: resolution, sample rate, SNR, ENOB, interface type, noise density, channel count
- CRITICAL: highlight that AD9680 and AD9208 use JESD204B serial interface, NOT parallel LVDS

4.3 Gap Analysis:
- SQNR improvement calculation using Eq. NF-11:
  - 8-bit to 14-bit: +36.1 dB (from 49.9 to 86.0 dB)
  - 8-bit to 16-bit: +48.2 dB (from 49.9 to 98.1 dB)
- State explicitly: "This is the single largest potential improvement in the entire AERIS-10 system" (from research findings)
- CRITICAL caveat (from Eq. NF-12): improvement only realized if analog chain gain keeps thermal noise above the new (much lower) quantization floor. Higher-resolution ADC exposes the analog chain noise that was previously masked by quantization.
- Warning sign from research: if "improvement" from 14-to-16-bit shows only 12 dB, someone used wrong baseline

4.4 Feasibility Assessment:
- CRITICAL Pitfall 2: JESD204B interface change
  - Artix-7 XC7A100T has NO GTH/GTY transceivers -- CANNOT natively support JESD204B
  - ADC upgrade (HWRES-04) is DEPENDENT on FPGA upgrade (HWRES-06)
  - Document this coupling explicitly with forward reference to Section 6
- If FPGA upgraded to AU15P/AU25P with GTH transceivers: ADC upgrade becomes viable
- Firmware impact: entire `ad9484_interface_400m.v` module must be rewritten for JESD204B lane interface
- Risk: analog chain re-optimization needed to exploit higher dynamic range

4.5 Recommendations:
- Highest-impact upgrade BUT requires paired FPGA upgrade
- Recommended investigation: evaluate AD9680 + AU15P as a paired upgrade path
- Priority: HIGHEST when combined with HWRES-06

**Section 6: FPGA Upgrade Path (HWRES-06):**

6.1 Current State:
- XC7A100T (Artix-7, 28 nm)
- Resources: 63,400 LUTs, 126,800 FFs, 135 BRAMs (36Kb), 240 DSP48E1 slices, 0 transceivers, 6 CMTs
- Estimated utilization from Phase 3: ~16,500 LUTs (~26%), ~88 DSPs (~37%), ~101 BRAMs (~75%) -- note these are theoretical estimates pending Vivado reports (Open Question 3 from research)
- Cross-reference `02_hardware/05_fpga_board.md` for clock domains (100/120/400 MHz), CDC synchronizers, BUFG usage

6.2 Literature Survey:
- Resource comparison table from 06-RESEARCH.md: XC7A100T vs AU10P vs AU15P vs AU25P
- CRITICAL observation from research: AU10P has FEWER LUTs (44K vs 63K) -- NOT a viable migration target despite being "entry" UltraScale+
- AU15P is the minimum viable upgrade: 77,760 LUTs (22% more), 576 DSPs (2.4x), 144 BRAMs, 12 GTH transceivers
- AU25P is the future-proof option: 141K LUTs (2.2x), 1,200 DSPs (5x), 300 BRAMs (2.2x), GTY transceivers
- DSP48E2 vs DSP48E1: 27x18 vs 25x18 multipliers (wider multiply for higher-precision processing)
- FT601 USB 3.0 compatibility: confirmed via Opal Kelly XEM8305 (AU15P + FT601 development board)

6.3 Gap Analysis:
- GTH transceivers enable JESD204B -- the key enabler for HWRES-04 (ADC upgrade)
- More DSP slices enable Phase 5 software improvements: larger FFTs, more complex matched filters, potential ML inference
- More BRAMs enable deeper range/Doppler buffers
- What current FPGA cannot do: support any ADC with JESD204B interface, run multiple FFT pipelines simultaneously

6.4 Feasibility Assessment:
- PCB migration complexity: HIGH (Pitfall 5 from research)
  - Different packages, I/O banks, pin assignments
  - Different voltage rails (UltraScale+ 0.85V core vs Artix-7 1.0V)
  - Different configuration modes
  - Entire PCB layout, constraint file, and power management must be redesigned
  - Clock tree redesign: different BUFG architecture, potentially new AD9523 outputs for JESD204B reference clocks
- NOT a drop-in upgrade -- if analysis describes it as "straightforward," the hardware integration has not been considered
- FT601 FIFO interface (32-bit, 100 MHz, LVCMOS33) compatible with AU+ HP I/O banks

6.5 Recommendations:
- AU15P recommended as minimum migration target (LUT headroom + GTH for JESD204B)
- AU25P recommended if Phase 5 software improvements require significant additional resources
- Pair with HWRES-04 (ADC upgrade) for maximum system improvement
- Recommended investigation: prototype with Opal Kelly XEM8305 board before committing to custom PCB
- Priority: HIGH -- enables the highest-impact upgrade (ADC resolution)
