**Document structure (from research):**

1. **Uniform linear array (ULA) geometry** -- Element positions along a line with spacing $d$. Far-field assumption (plane wave at each element). Path length difference between adjacent elements: $d\sin\theta$. Diagram description in prose (element positions, wavefront geometry).

2. **Array factor derivation** -- $AF(\theta) = \sum_{n=0}^{N-1} w_n e^{jn\psi}$ where $\psi = kd\sin\theta + \Delta\phi$. Explain each term. This is the foundational equation for all subsequent beamforming analysis.

3. **Beam steering** -- Set $\Delta\phi = -kd\sin\theta_0$ to steer the main beam to angle $\theta_0$. Show that this makes $\psi = 0$ (constructive interference) at $\theta = \theta_0$.

4. **Closed-form array factor** -- For uniform weights ($w_n = 1$), apply geometric series to get $AF(\theta) = \sin(N\psi/2) / \sin(\psi/2)$. Derive this step by step. Show the normalized form $|AF|^2 / N^2$.

5. **Half-power beamwidth** -- Derive $\theta_{3\text{dB}} \approx 0.886\lambda / (Nd\cos\theta_0)$ for broadside. Show how beamwidth broadens with scan angle ($\cos\theta_0$ factor). Physical interpretation: beam spreads as it steers away from broadside.

6. **Grating lobe conditions** -- Derive the GENERAL condition: $d(\sin\theta_0 + \sin\theta_\text{GL}) = m\lambda$ for integer $m \neq 0$. Per research Pitfall 3: do NOT just state "$d \leq \lambda/2$ prevents grating lobes." Instead: (a) derive the general condition, (b) show that for $d = \lambda/2$, grating lobes appear at $\sin\theta_\text{GL} = 2m - \sin\theta_0$, (c) for $\theta_0 = 0$ (broadside) the first grating lobe is at $\theta_\text{GL} = \pm 90^\circ$ (outside visible space), (d) for the AERIS-10 scan range of approximately $\pm 33^\circ$ (from parameter_table.md phase shift range), the grating lobe condition can be relaxed -- $d$ could be larger than $\lambda/2$ without grating lobes appearing in the scan range. Show this quantitatively.

7. **Element pattern and mutual coupling** -- Total pattern = array factor $\times$ element pattern. Brief discussion of mutual coupling effects on active element pattern vs isolated element pattern. Note that detailed coupling analysis belongs in calibration theory (Document 06).

8. **Amplitude tapering** -- Taylor and Chebyshev weighting for sidelobe reduction. Tradeoff: lower sidelobes = wider main beam. The weights $w_n$ implement the taper. Connect to the $w_n$ symbol: applying a window function to the array is amplitude tapering.

9. **2D beam pattern** -- Extension from 1D ULA to planar array. For the 8x2 subarray configuration, the 2D pattern is separable: $AF(\theta, \phi) = AF_x(\theta) \cdot AF_y(\phi)$ when rows and columns are independent. Brief derivation showing the separability condition.

10. **Beam pattern figures** -- Embed the SVG figures generated by Task 3: `![Beam pattern -- N=16 ULA, uniform weights](figures/beam_pattern_N16_uniform.svg)` in the closed-form array factor section and `![Beam pattern -- N=16 ULA, uniform vs Taylor weighting](figures/beam_pattern_N16_taylor.svg)` in the amplitude tapering section. Reference the figures in the text discussing beam characteristics.

Create `01_physics/06_calibration_theory.md` covering PHYS-07. Use equation prefix CAL with tags CAL-1 through approximately CAL-12.

**Document structure (from research):**

1. **Error model** -- Phase error $\delta\phi_n$ and amplitude error $\delta a_n$ per element. The actual element response is $(a_n + \delta a_n) e^{j\delta\phi_n}$ instead of the ideal $a_n$. Separate error sources: manufacturing tolerances, component aging, temperature drift, feed network imbalances.

2. **Array pattern with errors** -- $AF_\text{err}(\theta) = \sum_{n=0}^{N-1} (a_n + \delta a_n) e^{j(n\psi + \delta\phi_n)}$. Show how this differs from the ideal array factor. Derive that errors create a perturbation term added to the ideal pattern.

3. **RMS sidelobe level with random errors** -- Use the Mailloux result (per research "Don't Hand-Roll" guidance): $\overline{\text{SLL}} \approx (1/N) \sum (|\delta a_n / a_n|^2 + |\delta\phi_n|^2)$. For uniform weights and identically distributed errors: $\overline{\text{SLL}} \approx \sigma_a^2 + \sigma_\phi^2$ where $\sigma_a$, $\sigma_\phi$ are RMS amplitude and phase errors. Physical interpretation: errors raise the average sidelobe floor.

4. **ADAR1000 phase quantization** -- Per research Pitfall 5: model as DETERMINISTIC error (not random). Step size = 2.8 degrees (128 states over 360 degrees, 7-bit resolution). Maximum quantization error = half the step size = 1.4 degrees. Derive beam pointing error bound from the quantization error. Derive peak sidelobe level degradation. Show that 7-bit phase quantization is sufficient for moderate sidelobe requirements but creates a deterministic error pattern that differs from random errors.

5. **ADAR1000 amplitude quantization** -- The ADAR1000 has independent gain control per element (attenuator). Document the attenuator resolution and its impact on amplitude taper accuracy. The amplitude quantization limits how precisely Taylor/Chebyshev tapers can be implemented.

6. **Mutual coupling effects** -- Coupling matrix $\mathbf{C}$: the excitation at element $n$ induces currents in neighboring elements. Active element pattern = isolated element pattern modified by coupling. The ideal weights $w_n$ must be replaced by $\mathbf{C}^{-1} \mathbf{w}$ to achieve the desired pattern. Brief derivation showing the coupling correction.

7. **Calibration correction** -- Measurement-based calibration procedure: (a) inject known signal (e.g., far-field source or mutual coupling-based self-calibration), (b) measure per-element complex response, (c) compute correction vector as ratio of ideal to measured response, (d) apply correction via ADAR1000 phase/gain registers. Mathematical formulation of the correction.

8. **Residual error analysis** -- Post-calibration error bounds given ADAR1000 quantization limits. Even with perfect calibration measurement, the discrete phase/amplitude steps of the ADAR1000 create a floor on achievable correction accuracy. Derive the residual sidelobe level.

**Formatting:** Follow conventions.md. Symbolic only. Cross-reference beamforming theory for array factor and phase model. Reference parameter_table.md for ADAR1000 specifications.
