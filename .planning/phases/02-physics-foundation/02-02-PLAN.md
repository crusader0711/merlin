Create `01_physics/04_detection_theory.md` covering PHYS-04. Use equation prefix DET with tags DET-1 through approximately DET-20.

**Document structure (from research):**

1. **Binary hypothesis testing** -- $H_0$: noise only, $H_1$: signal + noise. Define the detection problem mathematically. Received signal models under each hypothesis.

2. **Neyman-Pearson lemma** -- Maximize $P_d$ subject to $P_{fa} \leq \alpha_0$. Likelihood ratio test $\Lambda(x) = p(x|H_1)/p(x|H_0) \gtrless \gamma$. Derive that this is the optimal detector.

3. **Gaussian noise model** -- Apply Neyman-Pearson to known deterministic signal in additive white Gaussian noise. Derive threshold in terms of Q-function. Express $P_{fa} = Q(\gamma/\sigma)$ and $P_d = Q((\gamma - A)/\sigma)$ where $A$ is signal amplitude.

4. **Square-law detector** -- Magnitude-squared of complex signal. Under $H_0$: exponential distribution (for envelope of complex Gaussian). Under $H_1$: non-central chi-squared distribution. Derive the PDF under each hypothesis.

5. **Swerling target models** -- Cases 0 (non-fluctuating), I (scan-to-scan fluctuation, Rayleigh RCS), II (pulse-to-pulse, Rayleigh), III (scan-to-scan, chi-squared 4 DOF), IV (pulse-to-pulse, chi-squared 4 DOF). State the RCS probability distributions. Explain physical meaning of each case.

6. **CA-CFAR derivation** -- Sliding window: cell under test (CUT) flanked by $N_\text{guard}$ guard cells and $N_\text{ref}$ reference cells. Estimate noise power from reference cells. Threshold = $\alpha \times$ estimated noise power. Derive threshold multiplier: $\alpha = N_\text{ref}(P_{fa}^{-1/N_\text{ref}} - 1)$. State the assumption: reference cells contain i.i.d. exponentially distributed noise samples (Swerling Case 0). Use the "Don't Hand-Roll" guidance -- use the standard formula from Skolnik/Richards.

7. **Detection probability curves** -- $P_d$ vs SNR parametric in $P_{fa}$ for Swerling Case 0 and Case I. Show how required SNR increases as $P_{fa}$ decreases. Note that these curves are typically computed numerically (no closed form for general case).

8. **CFAR loss** -- SNR penalty of CFAR vs fixed threshold. Show dependence on reference window size $N_\text{ref}$: CFAR loss decreases as $N_\text{ref}$ increases. Typical values: ~1 dB for $N_\text{ref} = 24$.

9. **Non-homogeneous environments** -- When CA-CFAR fails: clutter edges, multiple targets in reference window. Briefly motivate OS-CFAR and GO/SO-CFAR as alternatives (setting up Phase 5 SWRES-01 research). Do NOT derive these variants -- just state the problem and the direction.

**Formatting:** Follow conventions.md. Symbolic only. Reference LFM document for matched filter SNR gain. Cross-reference FMCW theory for radar equation SNR.
