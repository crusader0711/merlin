Section 2 - Literature Survey: Cover three approaches:
- MVDR (Minimum Variance Distortionless Response): Requires sample covariance matrix estimation and matrix inversion (O(N^3) for N=16). Published FPGA implementations require XCKU060/XCKU085-class FPGAs (4000+ DSP slices). Cite MathWorks MVDR reference and ScienceDirect 2024 paper. Artix-7 with 240 DSPs is significantly resource-constrained.
- LCMV (Linearly Constrained Minimum Variance): Similar computational requirements to MVDR. Additional constraint matrix allows null steering. Same FPGA feasibility concerns.
- Hybrid approach: Pre-computed weight tables with periodic MVDR/LCMV updates on host PC, downloaded to ADAR1000 via SPI. Moves computation off-FPGA but introduces latency. Quantify SPI transaction time for full 16-element weight update per Open Question 5 from research.
- Robust beamforming: Diagonal loading and worst-case optimization methods that reduce sensitivity to steering vector errors and ADAR1000 quantization. Lower computational cost than full MVDR.

CRITICAL: ADAR1000 7-bit phase quantization (2.8 deg steps) and 0.5 dB gain resolution limit the precision of any adaptive beamforming scheme. Analyze how quantization degrades adaptive null depth and pattern control.

Section 3 - Gap Analysis: Current system uses fixed beam steering tables (no adaptation). No interference rejection. No adaptive null steering. ADAR1000 quantization limits achievable null depth.

Section 4 - Feasibility Assessment: MVDR/LCMV on FPGA: INFEASIBLE on Artix-7 (need ~4000 DSPs). Hybrid host-computed: FEASIBLE but latency-limited by SPI update rate. Robust beamforming: MARGINAL (reduced complexity but still significant). Include Artix-7 resource tables showing why real-time MVDR is infeasible.

Section 5 - Recommendations: Hybrid host-computed MVDR as Priority 1 (feasible, avoids FPGA constraint), robust beamforming with diagonal loading as Priority 2 (lower complexity, potentially FPGA-feasible for small arrays), real-time FPGA MVDR as Priority 3 (requires FPGA upgrade per HWRES-06).
